## Metadata and interface

`/ai-disclosure.json` provides machine-readable scope and links. New native-data
exports identify real observational origin and AI-assisted processing separately.
Hashed/frozen source files and model receipts must not be rewritten to add labels:
use linked disclosure metadata or sidecars so their original hashes stay valid.
The application Methodology view links this disclosure; synthetic mode retains a
visible synthetic-data notice. HTML metadata points to the disclosure JSON.

The inventory is currently partial: only recorded/confirmed usage is asserted.
Do not claim no other AI use, human authorship of every contribution, or complete
human review without the team's confirmation.

## Submission wording

OpenAI Codex assisted with code generation, debugging, tests and documentation.
NASA FIRMS observations were obtained from NASA and were not synthesized by a
generative AI model. Derived summaries and statistical calibration/validation
outputs were computed by versioned scripts developed with AI assistance. Separate
demonstration fixtures contain explicitly labeled synthetic data. The frozen
calibration candidate failed the registered forward validation and remains
unapproved. The team is responsible for reviewing AI-assisted outputs and for
completing the disclosure of any additional tools and submission media.

## Source guidance

The full submission-guide page returned a gateway error during this review.
The GO Team's public answer explicitly permits AI with disclosure by content type:
https://github.com/nasa/spaceapps/discussions/1849 . It specifies descriptive
text/metadata acknowledgement for generated code/data and audio, visible marking
for generated images/videos, and restrictions on NASA branding in generated
content. Follow any additional current form requirements checked by the submitter.

The FortiGuard website-rating form is a separate web-filter categorization
process, not a Space Apps AI disclosure mechanism. No request is submitted to
FortiGuard automatically by this project.
